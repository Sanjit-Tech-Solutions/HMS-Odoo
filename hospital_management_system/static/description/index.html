Hospital Management System

Version: 17.0.1.0

Author: Sanjit Tech Solutions

This module provides an integrated solution for managing hospital operations such as patient registration, doctor interaction, ICU bed allocation, and medical billing.

1. Patient Registration

  • Register new patients with details like name, age, gender, contact info, and medical history.
  • Maintain a list of all registered patients.
  • View age in years and days (auto-calculated from DOB).

2. Doctor Log

  • Doctors can view the list of assigned patients.
  • Add observations, notes, and assign test machines (e.g., ECG, CT scan, X-ray).
  • Record diagnosis and treatment plan per patient.

3. ICU Bed Management

  • Displays a visual grid of ICU beds (10 default beds).
  • Beds appear as green (available) or red (occupied).
  • Click to assign a patient post-surgery or for critical care.
  • Booking includes patient details and admission dates.

4. Medical Billing

  • Generate billing records based on patient prescriptions.
  • Add medicine name, quantity, price, and total.
  • Print a professional invoice (QWeb PDF) for the patient with all medicines listed.
  • Automatic tax and subtotal calculation.

How to Use

  1. Install the module from the Apps screen.
  2. Access the HMS menu from the top navigation bar.
  3. Register patients using the “Patient” menu.
  4. Use “Doctor Log” to track patient observations and assign machines.
  5. Go to “ICU Bed Booking” to manage post-surgery bed assignments.
  6. Create medical bills from the “Billing” section and print invoices.
